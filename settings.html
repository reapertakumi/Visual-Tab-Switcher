Tab Switcher

Works like Alt+Tab: hold the modifier, tap the key to move, release to switch.

Shortcuts

Open switcher / next tabKeep holding the modifier and press the key again to move forward
Alt+Q
Previous tabMove backward through the switcher
Alt+Shift+Q
Change shortcutsBrowser shortcuts are managed on the extensions shortcuts page

While the switcher is open

Release AltSwitch to the selected tab
QTabNext tab
← →Move the selection
F2Search tabs in this window
F4Search bookmarks
EnterSwitch to the selected tab
DeleteClose the selected tab
EscCancel

Mouse: hovering a tab brightens it and shows its ✕ without changing the selection. Click to switch, click ✕ or middle-click to close, scroll the wheel to see more tabs.

Tab Search

Find any open tab by its title or address.

Search hotkeyOn a page: search all windows. In the switcher (even while holding Alt): search this window.
Use the hotkey on web pagesWhen off, the hotkey only works inside the switcher
Global search shortcutOptional browser shortcut that also works when the address bar has focus
Not set

Tip: you can also just start typing while the switcher is open. Every word must appear in the title or the address.

Bookmark Search

Open any bookmark without digging through folders.

Bookmark hotkeyOpens bookmark search; inside the switcher it switches to bookmarks
Use the hotkey on web pagesWhen off, the hotkey only works inside the switcher
Global bookmark shortcutOptional browser shortcut that also works when the address bar has focus
Not set
FoldersBookmarks appear in the same order as your bookmark bar, and folders are cards you can open with Enter. Type the start of a folder name and press Tab to complete it (/wo → /Work/). /Work/report searches inside a folder.
